# Código de conducta

Este repositorio existe para ayudar a desarrolladores a integrar la API de endpoint.pe. Pedimos a quien participe, en issues, pull requests o discusiones:

- Tratar a los demás con respeto, sin importar su nivel de experiencia, lenguaje favorito o lugar de origen.
- Hacer críticas al código, no a las personas.
- No publicar datos personales de terceros (nombres, DNI, direcciones) ni claves de API, propias o ajenas.
- Mantener las conversaciones en el tema del repositorio.

Los mantenedores pueden editar o eliminar aportes que no cumplan estas normas y, en casos repetidos, bloquear la participación. Si algo te incomoda, escríbenos a contacto@endpoint.pe.
